One line under 200 characters: the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM. The wallet has a personality (a vault with a bedtime), a reason (its keys lock at midnight), and a joke that lands in one breath (at 3 AM the only thing it signs is a noise complaint against its owner's thumb).

## Run it

```sh
node main.ts
```

This writes the excuse to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
